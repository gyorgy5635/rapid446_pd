# PD run map

Goal: animate labware movement between instruments for the MADSci protein design workflow, and keep
alternative protocol versions side by side. Started 2026-11-24 from `incoming/readme.txt`.

## Structure
- `protocols/<version>/protocol/`: the protocol itself (src/full_run.py, workflows/*.yaml, protocols/*.py), i.e. what goes to GitHub.
- `protocols/<version>/config/`: plates.json, layout.json, durations.json, source.json (provenance and link base).
- `protocols/<version>/viz/`: generated by `./build.sh <version>`; do not hand-edit.
- `protocols/full_protocol_24`: unmodified baseline copied from AD-SDL/rapid446_applications
  `Protein_Design/full_protocol_24`, branch PD_full_loop, commit e4bc261 (2026-11-11). Do not edit it; make variants with
  `./new_version.sh <from> <to> "title"`.
- `tools/`: extract_events.py (AST-only parse of full_run.py, never executes it), build_player.py,
  player_template.html, export_madsci_history.py. `tests/make_synthetic_history.py` makes FAKE data for testing only.

## Workcell facts confirmed by the user
- Layout follows `incoming/PD.arrangement.pptx`: Flex top-left; sealer, thermocycler (PCR), Hidex and peeler in a row;
  PF400 on a linear rail below them, able to reach everything; exchange bottom-left; OT-2 below the rail under the Hidex;
  plate nests to its right.
- Exchange = re-grip nest: place, home, pick up; `exchange_narrow`/`exchange_wide` are the same nest gripped on different sides.
- Flex A4 is the only Flex slot the PF400 serves (handoff); the Flex gripper moves plates between A4 and other slots.
- Equal screen time per step is fine; real durations are shown as text.

## Open items
- Durations are estimates. The lab server (146.137.240.20) was unreachable from the original machine; real timings need
  `tools/export_madsci_history.py` run on the lab network, with the output saved to `protocols/<version>/viz/madsci_history.json`.
- Upstream bug noted: in full_run.py, `A4_to_A2` points at `pcr_A2_to_A4.py` (only used in a commented-out block).
- Versions: `full_protocol_24_20261124` = single run, SYBR Green removed, controls rack → OT-2.
  `full_protocol_24_3round` = 3-round experiment (user requirements 2026-11-24); its `PLAN.md` holds the decisions,
  tip plan, assumptions and open items. Placeholder MADSci names there: `cold_block_ext`, `rack2_row1_nest1`.
- 3-round decisions from the user: PCR master mix column 10/11/12 per round, GG mix column 9 shared; cell-free 24 µL
  water + 6 µL diluted PCR; rounds sequential with new combinations each round; Flex staging B4/C4 can hold tip boxes
  for on-deck swaps (PF400 tip-box swapping still has issues).
- Each Opentrons run starts fresh tip tracking: in multi-round versions `full_run.py` counts tips (TipLedger) and
  passes start tips into protocols as `$..._tip_start` template variables.
